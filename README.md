# lite_ui

轻量 Flutter UI 组件库，封装常用弹窗、按钮、表单控件、文件上传等，开箱即用。

## 特性

- 组件高度可配置，样式默认值内联
- 支持泛型，灵活适配业务数据类型

## 依赖

| 包名           | 版本          | 用途                                                     |
| -------------- | ------------- | -------------------------------------------------------- |
| `file_picker`  | 12.0.0-beta.7 | 提供系统级文件选择能力，支持从本地存储选取任意类型文件   |
| `image_picker` | 1.2.3         | 提供图片选择与拍照能力，支持从相册选取或直接调用相机拍摄 |

## 安装

```yaml
dependencies:
  lite_ui: ^1.0.0
```

### ActionButton

操作按钮组件。基于 Flutter 原生按钮二次封装，保留水波纹、无障碍、主题等能力。

支持 6 种按钮类型：

- `elevated` — 凸起填充按钮（带阴影）
- `outlined` — 描边按钮
- `text` — 文字按钮
- `filled` — Material 3 填充按钮
- `toned` — 色调填充按钮（比 filled 更柔和）
- `icon` — 图标按钮

### ActionSheet

底部操作面板组件。以底部弹出 Sheet 的形式展示操作项列表，支持两种数据模式：

- **普通列表模式**：平铺展示所有操作项
- **分组模式**：按 Section 分组展示

包含标题、描述、可滚动操作项列表及取消按钮。

### DialogAction

居中弹窗组件，支持 5 种弹窗类型：

- `alert` — 提示弹窗（标题 + 内容 + 确认按钮）
- `confirm` — 确认弹窗（标题 + 内容 + 取消/确认双按钮）
- `input` — 输入弹窗（标题 + 输入框 + 取消/确认按钮）
- `multiAction` — 多操作弹窗（标题 + 内容 + 多按钮纵向排列）
- `custom` — 自定义内容弹窗（仅壳子，内容由外部传入）

### EmptyData

空状态数据展示组件。当列表、页面或模块没有数据时显示的占位组件。

- 支持 **8 种场景类型**（空数据、无权限、网络错误、搜索无结果等）
- 支持 **4 种布局风格**（默认、卡片、紧凑、极简）
- 可自定义图标、标题、描述及操作按钮

### FileUpload

文件上传组件，支持多种文件选择方式：

- 选择文件 / 选择相册 / 拍照 / 弹窗组合选择
- 支持单选与多选
- 可配置上传数量限制、允许的文件扩展名
- 内置卡片模式与列表模式两种展示样式
- 支持上传进度展示、文件预览、文件删除
- 头像模式：单文件时可自动裁剪为正方形头像展示

### InputContent

文本输入框组件，基于 Flutter `TextFormField` 封装：

- 支持 label 标签、formLabel 表单标签
- 支持密码输入模式
- 支持必填校验与自定义校验规则
- 可配置输入框样式（边距、填充色、提示文字等）

### InputNumber

数字步进器组件，左侧减号、中间输入框、右侧加号：

- 支持整数与小数两种输入类型
- 可配置最小值、最大值、步长
- 小数模式可控制小数位数
- 长按持续增减

### SelectModal

底部弹窗选择器，支持两种模式：

- `filterable` — 可过滤选择器（本地搜索过滤 + 动态数据合并）
- `remote` — 远程搜索选择器（异步搜索，适合大数据量场景）

支持单选与多选，泛型设计可适配任意数据类型。

### TreeSelect

树形选择器组件，以底部弹出面板形式展示层级数据：

- 内置搜索过滤功能
- 支持单选（选中即关闭）与多选（底部确认按钮）
- 提供 `TreeSelectHelper` 便捷调用方法
- 支持自定义节点展示

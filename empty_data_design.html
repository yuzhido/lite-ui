EmptyData 组件设计稿

lite_ui 空状态展示组件 — 四种预设场景 + 完全自定义

组件结构
icon (Widget) — 图标/插图
暂无数据 title (String) — 主标题
当前没有可显示的内容 description (String) — 描述
action (Widget?) — 可选操作
Default 默认空状态 — 列表/数据为空
暂无数据
当前列表没有内容，
请先添加数据
Search 搜索无结果 — 过滤/搜索场景
未找到相关结果
换个关键词试试？
Action 带操作按钮 — 可重试/添加
还没有内容
点击下方按钮添加
第一条数据
Network 网络异常 — 加载失败重试
网络连接失败
请检查网络设置后
重新加载
API 参数设计
参数 类型 默认值 说明
type EmptyDataType EmptyDataType.empty 预设场景类型：empty / search / noNetwork / error
title String? 自动（按 type） 主标题文字，不传则根据 type 使用默认文案
description String? 自动（按 type） 描述文字，不传则根据 type 使用默认文案
icon Widget? 自动（按 type） 自定义图标 Widget，不传则使用 type 对应的内置图标
iconBackgroundColor Color? 自动（按 type） 图标背景圆形颜色
actionLabel String? null 操作按钮文字，传 null 不显示按钮
onAction VoidCallback? null 操作按钮点击回调
actionWidget Widget? null 自定义操作区域 Widget（优先级高于 actionLabel）
titleStyle TextStyle? null 自定义标题样式
descriptionStyle TextStyle? null 自定义描述样式
padding EdgeInsetsGeometry? EdgeInsets.all(32) 组件外边距
用法示例
// 1. 最简用法 — 默认空状态
EmptyData()

// 2. 指定场景类型
EmptyData(
  type: EmptyDataType.search,
)

// 3. 带操作按钮
EmptyData(
  type: EmptyDataType.empty,
  actionLabel: '添加数据',
  onAction: () { // 跳转添加页 },
)

// 4. 完全自定义
EmptyData(
  icon: Image.asset('assets/empty.png'),
  title: '自定义标题',
  description: '自定义描述内容',
  actionWidget: ElevatedButton(...),
)

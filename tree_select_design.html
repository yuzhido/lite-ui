API 参数设计
核心数据模型、组件参数与回调定义
M
TreeSelectItem<V, D>
数据模型
属性类型必填说明
labelString✓显示文本
valueV✓实际值，用于提交
dataD?—原始数据对象
childrenList<TreeSelectItem>?—子节点列表
isLeafbool—是否叶子节点（默认自动判断）
disabledbool—是否禁用，默认 false
subtitleString?—副标题/描述
P
TreeSelect 组件参数
Widget / show()
参数类型必填说明
itemsList<TreeSelectItem>?—本地树形数据
multiplebool—多选模式，默认 false
layoutTreeLayout—vertical | cascade
cascadeLevelsList<String>?—级联列标题 ["省","市","区"]
onLoadChildrenLazyLoadCallback?—懒加载子节点回调
onSearchRemoteSearchCallback?—远程搜索回调
selectedValuesSet<V>?—初始选中值
checkStrictlybool—父子联动开关，默认 true
titleString?—弹窗标题
searchHintString—搜索框提示文字
onSelectOnSelectChange?—单选回调
onConfirmOnMultiSelectConfirm?—多选确认回调
C
回调 & 枚举定义
typedef / enum
名称签名说明
TreeLayout enum vertical 竖向缩进  |  cascade 横向级联
LazyLoadCallback Future<List<TreeSelectItem<V,D>>> Function(TreeSelectItem parent) 根据父节点加载子节点
TreeSearchCallback Future<List<TreeSearchResult<V,D>>> Function(String keyword) 远程搜索，返回带路径的结果
TreeSearchResult class 搜索结果：item + path (面包屑路径列表)
OnSelectChange void Function(V value, D? data) 单选回调
OnMultiSelectConfirm void Function(List<V> values, List<D?> datas) 多选确认回调
文件结构规划
tree_select 目录下的模块拆分
lib/src/tree_select/
├── index.dart            // 统一导出入口
├── model.dart            // TreeSelectItem + 回调 + 枚举
├── tree_select.dart      // TreeSelect.show() 弹窗入口
├── tree_vertical.dart     // 竖向缩进布局（单选/多选）
├── tree_cascade.dart      // 横向级联布局（单选/多选）
└── tree_widgets.dart     // 复用 UI 子组件

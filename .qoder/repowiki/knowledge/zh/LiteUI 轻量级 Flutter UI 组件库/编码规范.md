- 每个组件目录以 `index.dart` 作为对外导出入口，集中 re-export 该组件的主类和子模块，由根 `lite_ui.dart` 统一聚合暴露。
- 组件内部按 `models/`（数据模型与枚举）、`ui/`（UI 子组件）、`utils/`（工具函数）分层组织，保持职责单一。
- 主题系统通过 `LiteUITheme` InheritedWidget 提供静态 `of(context)` 方法获取 `LiteUIThemeData`，未设置时回退到 `defaults` 默认值。
- Widget 类普遍使用 const 构造函数并声明 `super.key`，遵循 Flutter 现代语法规范。
- 公共 API 通过 Dartdoc 注释说明用途和使用方式，关键类如 `LiteUIThemeData`、`LiteUITheme` 均附带完整文档块。

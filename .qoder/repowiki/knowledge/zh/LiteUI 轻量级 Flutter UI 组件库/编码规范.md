- 每个子组件目录提供 `index.dart` 作为对外导出入口，将内部多个文件重新暴露给调用方
- 复杂组件采用分层结构：`models/` 放数据模型与枚举，`ui/` 或 `widgets/` 放 UI 组件，`service/` 放业务逻辑，`utils/` 放工具函数
- 主题系统通过 `InheritedWidget` 实现，提供静态 `of(BuildContext)` 方法从上下文获取主题数据并回退到默认值
- 公共数据类型集中在 `lib/src/models/` 目录下，通过 `index.dart` 统一导出 callbacks、enum、select_item 等
- 组件对外 API 保持简洁，仅通过 `index.dart` 暴露必要接口，内部实现细节不直接暴露

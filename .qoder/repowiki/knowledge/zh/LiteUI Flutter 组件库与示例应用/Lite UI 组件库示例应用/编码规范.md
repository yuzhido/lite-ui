- 每个 demo 页面采用 StatefulWidget + State 类分离的模式，State 类命名遵循 _XxxPageState 私有前缀约定
- 组件演示统一通过 required、formLabel、onSaved、onSelect/onConfirm 等回调参数配置，保持 API 一致性
- 演示数据集中放在 lib/mock/ 目录下，以静态常量或 getter 形式暴露（如 ActionSheetMockData.defaultItems）
- HomePage 使用统一的 _buildNavItem 方法生成导航项，icon/title/subtitle/page 四元组描述每个入口
- 所有页面使用 Scaffold + AppBar + SingleChildScrollView 的标准布局结构，表单区域包裹在 Form 中并通过 GlobalKey<FormState> 管理验证

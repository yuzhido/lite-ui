### DropdownChoose
- 定义：下拉选择组件，是 lite_ui 库中的核心表单控件之一。支持单选和多选模式，可配置本地过滤或远程搜索两种数据获取方式。组件封装了完整的表单集成能力，包括必填验证、值显示模式（文本/标签/紧凑）、最大选择数量限制等功能。通过泛型设计适配任意数据类型，支持 value 和完整 data 对象的分离管理。
- 别名：下拉选择器、选择组件

### SelectModalContent
- 定义：选择弹窗内容组件，是 DropdownChoose 的内部实现组件。负责处理选择弹窗的展示逻辑，包括搜索过滤、选中状态管理、已选项查看等功能。支持本地数据过滤和远程搜索两种模式，内置加载状态管理和空数据处理。组件内部维护已选项的完整数据缓存，确保「查看已选」功能能正确显示 label。
- 别名：选择弹窗内容、弹窗选择器

### SelectItem
- 定义：选择项数据模型，定义了下拉选择组件中每个选项的数据结构。包含 label（显示文本）、value（实际值）、data（原始数据对象）、subtitle（副标题）、disabled（禁用状态）等字段。支持图标配置和禁用状态标签。泛型参数 V 和 D 分别代表 value 和 data 的类型，便于业务层灵活定义数据结构。
- 别名：选择项、选项数据

### SelectModalType
- 定义：选择器模式枚举，定义了两种数据获取方式：filterable（本地过滤模式）和 remote（远程搜索模式）。filterable 模式直接传入 items 数据，组件内部进行关键字过滤；remote 模式通过 onRemoteSearch 回调异步获取数据，适合大数据量场景。该枚举控制组件的行为模式和 API 约束。
- 别名：选择模式、数据源类型

### DisplayMode
- 定义：值显示模式枚举，定义了三种已选值的展示方式：text（单行文本，顿号分隔）、tags（每个值显示为 tag，横向滚动）、compact（显示前 N 个 tag，剩余以 '+M' 显示）。该模式控制 DropdownChoose 组件在表单中的值显示样式，默认值为 text。
- 别名：显示模式、值展示方式

### FormLayout
- 定义：表单布局枚举，定义了两种布局方式：row（行布局）和 column（列布局）。控制 DropdownChoose 组件中标签和输入框的排列方式，影响表单的整体布局和视觉效果。该枚举与其他表单组件共享，保持统一的布局风格。
- 别名：表单布局、布局模式

### onLabelsResolved
- 定义：标签解析回调函数，在远程搜索模式下使用。当只传递 selectedValues（只有 ID）而没有 selectedItems 时，组件在弹窗打开后通过远程搜索获取数据，匹配到已选值的 label 后触发此回调。回调参数为 value → label 的映射，仅包含本次新解析到的项，供父组件更新 selectedItems 使表单字段显示正确的 label 而非 ID。
- 别名：标签解析回调、label解析

### maxCount
- 定义：多选最大可选数量限制，仅在多选模式下有效。达到上限后列表项点击不再新增选中，但不影响取消选中操作。该参数用于控制用户选择的数量范围，避免过多选择导致的数据处理问题。组件内部会检查当前选中数量是否已达到上限。
- 别名：最大选择数、选择上限

### selectedValues
- 定义：初始选中项的 value 集合，用于设置组件的初始选中状态。在编辑场景中，后端可能只返回 ID 列表而不是完整数据。该参数与 selectedItems 同时传递时，长度必须相等。组件会优先使用 selectedValues，如果为空则从 selectedItems 中提取 value 集合。
- 别名：选中值集合、初始选中值

### selectedItems
- 定义：已选中项的完整数据列表，用于确保回显时这些项一定出现在列表中，不受搜索过滤影响。适用于编辑场景：当后端返回完整数据时传入，确保查看已选时能显示 label。与 selectedValues 同时传递时，长度必须相等。组件内部会缓存这些数据用于「查看已选」弹窗的回显。
- 别名：选中项数据、已选完整数据

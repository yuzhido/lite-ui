- 每个组件目录都提供 `index.dart` 作为该组件的对外导出入口，由根 `lite_ui.dart` 统一 re-export，形成单一导入点。
- 组件内部按职责分层：`models/` 存放数据模型与枚举、`ui/` 存放 UI 子组件、`utils/` 存放工具函数、`service/` 存放业务服务，保持关注点分离。
- 主题系统通过不可变的 `LiteUIThemeData` 配置类配合 `InheritedWidget` 形式的 `LiteUITheme` 提供全局样式，组件通过静态 `of(context)` 方法获取主题。
- 所有公共 API 集中在 `index.dart` 中导出，具体实现文件命名以功能语义为主（如 `dialog_alert.dart`、`tree_item.dart`）。
- 枚举与回调类型统一放在 `models/enum.dart` 和 `models/callbacks.dart` 中集中管理，避免分散定义。

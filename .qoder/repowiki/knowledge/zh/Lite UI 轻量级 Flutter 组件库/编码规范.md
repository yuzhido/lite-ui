- 每个组件目录遵循 `index.dart` 统一导出 + `models/` 数据模型 + `ui/` UI 子组件的分层结构，对外仅暴露 `index.dart`。
- 组件属性通过构造函数参数声明并配合 `assert` 校验入参合法性（如 `type` 与 `items`/`onRemoteSearch` 的互斥关系）。
- 表单类组件继承自 `FormField<String>` 以集成 Flutter 表单验证体系，通过 `validator`、`autovalidateMode`、`onSaved` 统一管理校验与保存逻辑。
- 状态变化通过 `setState` 触发重建，内部临时状态（如 `_cleared`、`_isExpanded`、`_cachedRemoteItems`）与外部 widget 属性解耦。
- 后缀图标行为通过 `SuffixIconLabel` 组件抽象，根据 `selectedValue(s)` 和 `isExpanded` 动态切换 close/展开箭头图标。
